## 🛠️ Setup

1. **Install Python 3.7+**
   ```bash
   python --version
   # Python 3.12.x ✅
   ```

2. **Install PyCharm Community** (free)
   - [jetbrains.com/pycharm](https://jetbrains.com/pycharm)
   - Create new project → boom, you're ready

3. **Run code**
   - In PyCharm: `Right-click → Run`
   - Or terminal: `python your_file.py`
