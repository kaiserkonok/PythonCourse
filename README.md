# Learn Python from Zero to Hero

A comprehensive YouTube course covering Python programming from the basics to advanced concepts.

## Course Structure

```
PythonCourse/
├── module_01_foundations/      # How Python works, environment setup
├── module_02_data_memory/       # Variables, types, memory management
├── module_03_operations/      # Arithmetic, comparison, logical operators
├── module_04_control_flow/   # Conditionals, loops, control flow
├── module_05_data_structures/ # Lists, tuples, dicts, sets
├── module_06_functions/      # Functions, parameters, recursion
├── module_07_oop/           # Classes, inheritance, encapsulation
└── module_08_advanced/      # Errors, files, decorators, generators
```

## Each Topic Contains

- **`.md`** - Presentation slide for YouTube video
- **`.py`** - Practice code for students

## Getting Started

1. Install Python 3.x from python.org
2. Install PyCharm Community
3. Open a module folder
4. Run the `.py` files

## Running Code

```bash
python module_01_foundations/01_how_python_works.py
```

Or in PyCharm: Right-click → Run
